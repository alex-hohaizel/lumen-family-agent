# Одноразовий вхід у ChatGPT для Люмена

Поточний запуск уже підключений до ChatGPT: сесія на Render, активна модель **GPT-6.1-Sol**, відповідь перевірена. Повторювати вхід зараз не потрібно. Нижче наведені кроки для повторної авторизації або нової інсталяції. Це не вхід у GitHub чи Render. Нову платну підписку або API-кредити ця інструкція не оформлює.

## Комп’ютер: найкоротший шлях

1. Установіть [Node.js 24 LTS](https://nodejs.org/en/download). Розпакуйте актуальний архів Люмена. Відкрийте термінал у папці, де є `package.json`. На Windows можна відкрити цю папку, в адресному рядку Провідника написати `cmd` і натиснути Enter.
2. Виконайте послідовно:

   ```sh
   npm ci
   npm run build
   npm run login
   ```

3. Термінал видасть повне посилання **Continue with ChatGPT**. Відкрийте його у браузері на цьому самому комп’ютері. Не закривайте термінал. Виберіть потрібний ChatGPT-акаунт/workspace й підтвердьте показаний доступ для **Lumen Telegram**. За появи платної пропозиції зупиніться та звірте її окремо.
4. Успіх означає сторінку **«Люмен підключений»** і повідомлення **«Вхід завершено»** у терміналі. У `runtime/accounts.json` буде захищена сесія. Файл `runtime/host.json` переносити не потрібно.

Посилання діє протягом 10 хвилин і створюється тільки запущеною командою. Статичного посилання «увійти й підключити цього бота» немає. `127.0.0.1:1455/auth/callback` має повернутися на пристрій із терміналом; відкривання комп’ютерного посилання на іншому телефоні цей callback не доставить.

## Android без комп’ютера

Для телефона підготовлено окремий файл **Lumen_ChatGPT_Phone.sh**. Він містить програму входу та потрібні JavaScript-залежності, тому не потрібно розпаковувати весь проєкт, встановлювати npm чи самостійно збирати TypeScript.

1. Установіть [Termux із F-Droid](https://f-droid.org/en/packages/com.termux/) і збережіть `Lumen_ChatGPT_Phone.sh` у папку **Download / Завантаження** телефона.
2. У Termux виконайте `termux-setup-storage` та дозвольте доступ до завантажень. Потім виконайте:

   ```sh
   bash ~/storage/downloads/Lumen_ChatGPT_Phone.sh
   ```

3. Файл за потреби оновить пакети Termux, встановить безкоштовний Node.js разом із бібліотекою `libc++`, перевірить запуск Node.js і цілісність програми та відкриє браузер для особистого входу **Lumen Telegram**. Залиште Termux працювати й підтвердьте доступ у браузері цього самого телефона.
4. Після успіху відкриється локальна сторінка з кнопками **Копіювати підключення** і **Відкрити Render**. Скопіюйте підключення та вставте його в Secret File `chatgpt-accounts.json` за кроками на сторінці. Після **Save and deploy** напишіть лише «Сесію додано в Render».

Програма зберігає сесію в приватній папці `~/lumen-phone-login/runtime/` з правами власника; не переносить її у Downloads, не показує в терміналі та не запускає другого бота. Сторінка перенесення слухає лише `127.0.0.1`, потребує випадкового ключа та закривається через 30 хвилин. Вона не переносить сесію на Render автоматично: особистий вхід і вставлення у власний Render виконує користувач. Жодних нових ресурсів, API-кредитів чи підписок цей файл не створює.

Файл зібраний і перевірений на цілісність та автономне завантаження залежностей; перевірки захисту локальної сторінки пройдені. Повний OAuth на конкретному Android-телефоні ще не перевірений. Якщо Android не надає Termux доступ до Downloads, спочатку треба дозволити цей доступ у системних налаштуваннях або скопіювати файл у приватну папку Termux через файловий менеджер.

### Якщо Node.js показує `CANNOT LINK EXECUTABLE` / `__hash_memory`

Така помилка може виникнути, якщо новий Node.js установлений зі старою бібліотекою `libc++`. Попередня версія файла запуску не виконувала повного оновлення пакетів. У Termux виконайте:

```sh
pkg update -y && pkg upgrade -y && pkg install -y libc++ && node --version && bash ~/storage/downloads/Lumen_ChatGPT_Phone.sh
```

Команда спершу оновлює пакети й перевіряє запуск Node.js, а потім продовжує вхід тим самим файлом. Повторно завантажувати файл або перевстановлювати Termux для цієї спроби не потрібно. Якщо `node --version` знову показує ту саму помилку, виконайте `pkg reinstall -y libc++ nodejs-lts`, перевірте `node --version` і повторіть запуск файла.

### Якщо після копіювання вставляється тільки назва файла

На сторінці перенесення тепер завжди доступна кнопка **Показати текст для ручного копіювання**. Вона відкриває повне підключення в локальному полі. Затисніть текст → **Виділити все → Копіювати**, потім вставте його в **Contents** у Render. Вміст має починатися з `{`; сторінка також показує його довжину. Назва файла заповнюється в окремому полі Render.

Для вже встановленої на телефоні попередньої версії є маленький файл **Lumen_ChatGPT_Manual_Copy.sh**. Збережіть його в Downloads, у Termux зупиніть попередню сторінку через **CTRL → C** і виконайте `bash ~/storage/downloads/Lumen_ChatGPT_Manual_Copy.sh`. Він оновлює лише код локальної сторінки перенесення та використовує збережений вхід; повторної авторизації не проводить. Збірка цього файла: `npm run build`, потім `python3 scripts/build-phone-copy-fix.py`.

### Ручний варіант із повним архівом

Це альтернативний шлях із локальним Node.js. Наявність Node.js 24 у Termux перевірена за офіційним пакетом; повний OAuth на конкретному телефоні ще не перевірений.

1. Установіть Termux з [офіційного рекомендованого джерела F-Droid](https://f-droid.org/en/packages/com.termux/). Завантажте актуальний ZIP Люмена в Downloads.
2. У Termux виконайте:

   ```sh
   pkg update -y
   pkg upgrade -y
   pkg install -y libc++ nodejs-lts npm unzip
   termux-setup-storage
   ```

   Дозвольте доступ до завантаженого архіву. Переконайтеся: `node --version` показує версію не нижче 24.
3. Розпакуйте архів у приватну домашню папку Termux, а не в спільне сховище Android:

   ```sh
   mkdir -p ~/lumen-login
   unzip ~/storage/downloads/Lumen_Telegram_v1.1.0.zip -d ~/lumen-login
   cd ~/lumen-login/Lumen_Telegram_v1.1.0
   ```

   Якщо завантажений файл має іншу назву, підставте її.
4. Виконайте ті самі три команди `npm ci`, `npm run build`, `npm run login`. Відкрийте видане повне посилання у Chrome **цього самого телефона**, залишивши Termux працювати. Очікуйте обидва повідомлення про успіх, як у комп’ютерному варіанті.
5. Для передавання в Render відкрийте `runtime/accounts.json` локальним редактором Termux і скопіюйте вміст безпосередньо у Secret File в Render. Не публікуйте файл у чаті чи групі. Наприклад, можна встановити `nano` через `pkg install nano`, відкрити `nano runtime/accounts.json` і працювати лише локально. Не робіть скриншотів із вмістом. Після вставлення очистьте буфер обміну телефона.

Не запускайте повного локального бота: постійний екземпляр уже працює на Render.

## Перенесення сесії в Render

Відкрийте [Environment саме Люмена](https://dashboard.render.com/worker/srv-dbfl0je7bikc73dvg0qg/env). Якщо Render просить вхід, використайте той самий **Google**-акаунт, під яким створено сервіс.

1. У розділі **Secret Files** натисніть **Add file**.
2. У **File name** введіть рівно `chatgpt-accounts.json`.
3. Відкрийте **View secret file**, у полі **Contents** вставте повний вміст локального `runtime/accounts.json`, натисніть **Done**. Це пряме передавання сесії у власний Render-сервіс; не вставляйте її у ChatGPT-переписку.
4. У меню біля кнопки збереження виберіть **Save and deploy**. Цей варіант використовує наявну збірку. Дочекайтеся нового успішного deploy та імпорту сесії. Самого **Save only** недостатньо для запуску з новим файлом.
5. Далі повідомте лише **«Сесію додано в Render»**. Токени, коди входу та файл у чат надсилати не потрібно. Після цього можна перевірити каталог моделей і справжню відповідь на сервері.

Не переносіть `host.json`: Render уже має власний постійний ідентифікатор хоста. Після перенесення не запускайте локальні `models`, `probe` чи другого бота з копією сесії: подальше оновлення токенів має виконувати один сервер.

## Вибір моделі й група

Адміністративне продовження після імпорту:

1. У [Render Web Shell](https://dashboard.render.com/worker/srv-dbfl0je7bikc73dvg0qg/shell) виконати `npm run models`. Це отримує фактичний каталог акаунта. Не підставляти вигадану назву моделі.
2. Задати вибраний ID як `OPENAI_MODEL` у Environment через **Edit** → **Add**, зберегти й розгорнути з наявної збірки. Перевірити `npm run probe`: має бути завершена відповідь, а не лише успішний HTTP-запит.
3. Відкрити особисте посилання активації зі свого Telegram, натиснути Start і додати @lumen_family_agent у потрібну групу кнопкою. Команда прив’язки та обмеження на двох учасників не потрібні.
4. Сказати «Люмен, привіт, познайоммося». Перевірити живий діалог, пам’ять і природне прохання пограти. Основна взаємодія не потребує команд або вибору режимів. Актуальна інструкція — README.md, зміни — RELEASE_1_2_1.md. До додавання групи реальний діалог у ній не вважається перевіреним.

## Якщо вхід не завершився

- `oauth_timeout`: запустіть `npm run login` ще раз і використайте нове посилання; старе більше не діє.
- `oauth_callback_port_busy`: закрийте попередній процес авторизації, звільніть локальний порт 1455 і повторіть вхід. Не змінюйте callback на адресу Render.
- Сторінка `127.0.0.1` не відкривається: перевірте, що браузер і команда працюють на одному пристрої, а термінал не закритий.
- `chatgpt_plan_permission_missing` або відмова доступу: потрібний scope не виданий цьому акаунту/плану. Не перемикайтеся автоматично на платний API. Для діагностики достатньо назви помилки без повного URL чи секретів.

Офіційні джерела: [локальний OAuth](https://developers.openai.com/siwc/token-sharing-open-source/sign-in), [перенесення на власний сервер](https://developers.openai.com/siwc/token-sharing-open-source/self-hosted-vms), [Termux installation](https://github.com/termux/termux-app#installation), [Node.js LTS для Termux](https://github.com/termux/termux-packages/blob/master/packages/nodejs-lts/build.sh).
