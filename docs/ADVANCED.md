# Резервні команди та технічні налаштування

Для звичайного користування достатньо людської мови. Це додатковий довідник, а не сценарій, якого мають дотримуватися учасники.

«Нагадуй нам обом щодня о 04:00 про картоплю» створює одну спільну серію й одне повідомлення в цю тему на кожну дату. Для простого спільного нагадування достатньо чіткого доручення. Автор, явно названий і розпізнаний співучасник або адміністратор можуть зупинити всю shared серію. Ім’я людини в предметі нагадування (наприклад, день її народження) саме по собі не надає права керування.

«Видали ці нагадування про картоплю для обох» припиняє відповідні дозволені серії. «Скасуй лише найближчий повтор» залишає наступні дати. Якщо обсяг справді неоднозначний, Люмен ставить одне конкретне запитання; відповісти можна в тій самій темі без повторення імені бота. Заперечення, запитання, цитата й пересланий текст не є погодженням. Приватні записи залишаються особистими: автор може скасувати свій запис явним private-запитом за назвою або точним ID у вихідній темі, отримавши відповідь без приватних подробиць. У великій вибірці показується ознака неповного пошуку; частковий перегляд не доводить відсутність і не означає скасування всього набору.

| Команди | Призначення |
|---|---|
| `/help`, `/menu`, `/capabilities`, `/status` | Довідка та стан |
| `/notes`, `/memory`, `/reminders`, `/rules`, `/skills` | Перегляд даних своєї групи |
| `/style short\|balanced\|detailed`, `/humor off\|light` | Особистий стиль; працюють і звичайні прохання |
| `/games`, `/game назва`, `/stopgame` | Резервний запуск готової механіки. Вільні ігри запускає модель із діалогу |
| `/pause`, `/consent`, `/forget фрагмент`, `/forget_all` | Пам’ять; поновлення й повне очищення перевіряють права |
| `/character текст`, `/character reset`, `/character undo` | Постійний характер групи, лише власник підключення |
| `/models`, `/model ID` | Каталог і модель, лише власник; автоматичної підміни немає |
| `/mood hello\|happy\|thinking` | Додаткові оригінальні анімації Люмена |
| `/retry ID` | Явний повтор невизначеної доставки; можливий дубль |

Старі назви quiet/social/host залишено для сумісності даних. Для живої групи достатньо сказати «спілкуйся вільніше», «без ініціативи» або «тільки коли покличемо»; налаштування всієї групи перевіряє власник/адміністратор. Роль помічника, співрозмовника чи ведучого модель обирає за діалогом.

Фонові можливості об’єднуються в межах теми: пауза 2 с між повідомленнями, максимум 8 с до розгляду; після розгляду — щонайменше 45 с до нової фонової оцінки. Базова пауза між самостійними репліками в темі — 120 с, загальний захист — не більше 4 таких включень на групу за 10 хвилин. Це лише верхні межі: модель може промовчати. Прямі звернення та активні діалоги мають пріоритет. Власні паузи, відмінні від попереднього стандартного значення 45 хв, переносяться; нові явно задані паузи теж зберігаються. Перед постановкою відповіді й самою доставкою знову перевіряються актуальність, тиха година, пауза пам’яті та налаштування групи.

Пауза між сказаними репліками й груповий ліміт рахуються за підтвердженою доставкою. Останнє свіже повідомлення може дочекатися оцінки після 45-секундної паузи; продовження попередньої розмови отримує шанс і від одного учасника до старих порогів кількості реплік. «Люмен, помовчи, я допишу» тимчасово зупиняє самостійні включення в цій темі. Наступне пряме звернення автора поновлює цей діалог; прямі запити інших учасників теж працюють. Це стан конкретного діалогу, а не постійна зміна характеру чи глобальних налаштувань.

Звернення, кнопки й нагадування зберігають початкову тему Telegram. General у Bot API має відсутній/нульовий thread; історичний ID1 зберігає окрему ідентичність до доказової звірки. `/status` пояснює відому помилку закритої/відсутньої теми чи прав бота без тексту приватного результату. Фактичне отримання звичайних повідомлень залежить від Telegram Privacy Mode та прав у групі.

Для ChatGPT немає додаткової межі застосунку у 200 звернень на добу. `LUMEN_DAILY_TURN_LIMIT=0` залишає ліміти підписки; додатне значення задає власний бюджет на групу. Для окремого API-режиму за відсутності додатного налаштування збережено захист 200 основних звернень/підсумків на добу. Запити уточнення джерел можуть включати кілька викликів моделі. Генерація зображень, якщо її окремо підключили, має попередню межу 5 за 24 години. Це внутрішні налаштування, не опис тарифу OpenAI.

Пам’ять не обмежена робочою вибіркою учасників у контексті. У базі зберігаються отримані повідомлення й відомі імена; модель бачить обмежений релевантний контекст і може звернутися до перегляду/пошуку. Великі результати та зміни обробляються порціями. Це обмеження одного запиту, а не заборона участі нових людей.

Самовстановлення сторонніх інструментів, довільний SQL, shell, приватні адреси, автоматичний платний API fallback та пересилання пам’яті між чатами відсутні.
