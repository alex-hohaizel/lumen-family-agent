## Погоджені витрати та керування змінами

| Ресурс | Базова ціна за місяць |
|---|---:|
| Workspace Hobby | $0,00 |
| Worker, один екземпляр | $7,00 |
| PostgreSQL з 1 ГБ сховища | $6,30 |
| Постійний диск worker, 1 ГБ | $0,25 |
| **Разом** | **$13,55** |

Сума відображена на фактичному екрані Render перед створенням і окремо погоджена власником. Це регулярна плата за активні ресурси, з пропорційним обліком неповного місяця; виставлення рахунку — на початку наступного місяця. Попередня оцінка $13,25 була виправлена до активації: вона не враховувала $0,30 за сховище бази.

Понад включені 5 ГБ/місяць вихідного трафіку можливе автоматичне нарахування $0,15/ГБ. Тому $13,55 — базова вартість, а не жорсткий загальний ліміт рахунку. Додаткові витрати на build pipeline обмежені до $0; після включених хвилин збірки зупинятимуться. Автоматичне розширення сховища PostgreSQL вимкнене. Worker має один екземпляр, auto deploy вимкнений; Blueprint Auto Sync переведений у **No / Sync paused**. Нові платні дії, збільшення ресурсів, API-витрати й підписки потребують окремого попередження про точну вартість і підтвердження власника.

## Що ще не виконано

Прив’язка цільової приватної групи, дві згоди та перевірка справжнього діалогу, адаптивності й анімованих реакцій у ній.

## Послідовність продовження

1. Використати вже запущений Render-сервіс; нові ресурси не потрібні. Вхід у ChatGPT повторювати не потрібно, Termux можна закрити.
2. У потрібній приватній групі додати @lumen_family_agent. Скопіювати фактичний `LUMEN_PAIRING_CODE` з Render Environment і надіслати `/bind <код>` у цій групі. Потім кожен учасник надсилає `/consent`. Privacy Mode вимкнений; права адміністратора боту не потрібні.
3. Перевірити `/status` і справжню відповідь на звернення до Люмена. До цього жива робота саме у групі не підтверджена.
4. Подальше оновлення ChatGPT-сесії виконує один Render-процес. Локального бота з копією сесії не запускати. Для повторної авторизації або нової інсталяції — [окрема інструкція](CONNECT_CHATGPT.md).

## Наскрізна перевірка в групі

| Дія | Що має бути видно |
|---|---|
| `/status` | Дві згоди, модель, звичайні повідомлення доступні, немає проблем доставки |
| «Люмен, привіт. Відповідай одним реченням» | Справжня завершена відповідь ChatGPT у цій групі |
| `/mood happy`, `/mood hello`, `/mood thinking` | Три плавні анімовані реакції без службових підписів |
| Перший: `/style short`; другий: `/style detailed` | Окрема докладність у відповідях кожному |
| «Люмен, запам’ятай: перевіряємо запуск»; `/notes` | Нотатка з автором і справжнє підтвердження збереження |
| Явне нагадування на близький конкретний час | Доставка в зазначений момент за Europe/Kyiv |
| `/game story`, по одному ходу кожному | Чергування, збереження стану після одного контрольованого рестарту |
| `/pause`, тестова репліка, `/status` | Новий текст не зберігається та не передається моделі; для поновлення дві згоди |

`npm run smoke` додатково перевіряє токен, відсутність webhook-конфлікту, базу, прив’язку/згоди, доступність моделі й завершену відповідь. Він не читає `getUpdates` і не надсилає групових повідомлень. Поле `live_group_dialogue_verified` лишається `false`: ця команда не підміняє живий діалог.
