## Приймання конкретної зміни медіа

Зміна починається з відтвореного дефекту, exact accepted control та збережених originals/recipe. Для кожного підозрілого/зміненого файла вести accepted_unchanged / suspect / reproduced_defect / repaired / visually_reviewed / device_observed. Перевірити ідентичність, пропорції/обличчя/лапи/вуха/одяг, чистий alpha, емоцію й сцену, topology/keypose correspondence, предмети/опору/контакти, anticipation/action/settle, траєкторію/швидкість, повний loop у реальному й уповільненому темпі. Ghosting, dissolve несумісних поз, зайві кінцівки, здвоєння, стрибки чи зникнення деталей — причини адресного repair. Whole-image wiggle або додаткові кадри не підміняють сцену й якісний рух; contact sheet доповнює анімацію.

Перед freeze дочекатися завершення кожного encoder. Probe/full decode/order/frame count/duration/alpha/bounds/blank-black/duplicate checks та SHA виконати на остаточних frozen copies; перед immutable manifest hashes повторно звірити. Derived frames називати похідними; нові generated sources не оголошувати старими original atlas/timestamp. Зберегти input/output SHA, prompt/recipe/crop/resize. Незалежний FINAL не переписувати: виправлення оформлюється addendum з parent SHA й незалежним closure. Item→hash→provider file→позиція перевіряються окремо від human/mobile acceptance.

Музика в монтажі — чинна можливість за наданим джерелом; нова генерація/voice synthesis потребують іншого маршруту й дозволу. Перевірити actual video/audio streams, timeline/order/framing/captions, trim/loop/mix/fades/levels, mux/duration/decode/size/access/delivery та фактичний звук. Без `audio mapping` або за `-an` ролик не називається музичним. Вимога музики походить із чинного авторського прохання/версії мети; model flag, retry чи втрачений source не скасовують її. Відсутній трек/права — вирішальне уточнення, а не вигаданий URL/ліцензія. Actor/topic/audience/provenance/cancel/recovery/receipt зберігаються; private output та notice не потрапляють у групу без повноваження.
