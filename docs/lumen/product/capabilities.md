## Незавершена ресурсна робота

**status:** local_uncommitted_wip_not_accepted_or_deployed

**owner:** Existing project WIP; next integrator must retain exact bytes and establish actual owner before editing.

**contract:** Один worker/Auth lease; numeric-only cgroup v1/v2 or node-only memory sampler; bounded heavy-work admission/queues, Chromium idle cleanup, scheduling telemetry and resource-denial recovery. Current source and local-only docs/RESOURCE_MEMORY.md are canonical for this WIP.

**limits:** Один heavy callback; до 8 очікувачів/30 s; browser queue до 4 включно з активною операцією. При відомому ліміті current+reserve <=0.9*limit; reserve192 MiB browser/PDF/DOCX preview,128 MiB інші. Один safe reclaim/recheck; невідомий limit не вигадується. Admission не є allocation cap або гарантією від OOM.

**recovery:** Task resource denial → needs_input без автоматичного model-step; claimed effect лишається uncertain і потребує reconcile; media зберігає repair/materials; visual повертається в pending без decode-attempt та із cooldown30 s; cancel/forget/revision fences зберігаються.

**telemetry_privacy:** Лише numeric sampler fields, timestamp, finite phase/kind; без тексту, URL, назв документів, arguments/results, chat/user/task/source IDs чи process command line. Logger failure не змінює outcome.

**validation:** Source inspected for documentation. Existing/new product tests and long-session/Render memory acceptance not rerun or certified here.

**portability:** docs/RESOURCE_MEMORY.md and six new tests/resource-memory.ts are untracked local-only inputs. A clean clone of HEAD lacks them; cold handoff must carry unchanged WIP bytes plus hashes, not only links.
