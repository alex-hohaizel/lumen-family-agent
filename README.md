# Люмен

**Версія коду 1.13.2 · GPT-6.1-Sol.** Telegram-співрозмовник із пам’яттю окремої групи, приватними дорученнями, іграми та роботою з матеріалами. Спілкуйтеся звичайними словами: звернення на ім’я, @згадка, reply або зрозуміле продовження діалогу.

[Журнал змін](CHANGELOG.md) · [Випуск](docs/RELEASING.md) · [Супровід](docs/OPERATIONS.md) · [120 стікерів](https://t.me/addstickers/Lumen_120_Emotions_by_lumen_family_agent)

1.13.2 спрощує перевірки й пакування. Повний функціональний набір проходить у CI; сервер запускає окремий пакет без тестів, прев’ю й авторської історії. Захищений фінальний крок прибирає матеріали збірки та дубль залежностей із native build. Усі 120 анімацій, їхні ID, емоції та порядок відповідають затвердженому набору 1.13.1. Модель, голос, дані чатів, згода та приватність збережені. Номер коду не є підтвердженням деплою: фактичний commit і результат доставки перевіряються в Render та журналі запуску.

## Можливості

| Прохання або ситуація | Поведінка |
|---|---|
| Звернення, reply, повернення до спільної теми | Враховує контекст, адресата й темп; може доречно допомогти чи пожартувати, без обов’язку коментувати все |
| «Список покупок: хліб, молоко», потім «Ще сир» | Зберігає звичайний список; покупка, запаси та витрати мають окремий облік |
| «Завтра о дев’ятій нагадай» або «зроби це» | Уточнює лише невідоме; враховує часовий пояс, повтори, перенесення й окремий стан виконання |
| Гра, вікторина, голосування, спільна активність | Збирає згоду потрібних учасників, зберігає ролі, вибори й рахунок; довгі пояснення відкриваються окремо |
| Особисте прохання, чернетка, приватна відповідь | Доступ має належна аудиторія; перенесення приватного результату до групи потребує повноваження |
| Пошук, сайт, дозволений конектор | Використовує доступні інструменти й актуальні джерела; не називає непідтверджену дію завершеною |
| Фото, документ, відеофрагмент, стікер | Працює з фактичним доступним матеріалом, відрізняє прочитане від невідомого |
| PDF/DOCX/XLSX, альбом, короткий ролик із наданою музикою | Готує й перевіряє результат, доставляє відповідному адресату; новий платний генератор або голос не ввімкнений |
| Складне доручення, навчання, спільний проєкт | Зберігає мету, прогрес, залежності й можливість скасування; незалежна частина роботи може завершитися окремо |
| «Призупини пам’ять», виправлення або видалення | Застосовує чинні правила згоди, авторства, паузи й видалення до залежних матеріалів |

Теми належать своїй групі. Мова групи й особисті побажання учасників зберігаються окремо. Самостійну участь можна вимкнути словами «Люмен, без ініціативи». Повний опис доступів і службових команд — у [ADVANCED](docs/ADVANCED.md).

## Стікери

Канонічний набір містить 120 сцен мишеняти Люмена. 1.13.1 адресно виправила 35 анімацій; 1.13.2 не змінює жодного WEBM. Публікація звіряє точні байти, хеші, порядок, emoji й приналежність до набору до запуску чатів. Checkpoint дозволяє продовжити непевну операцію без створення дубльованого набору.

Люмен сам обирає стікер як рідкісний емоційний акцент. Пряме прохання надіслати стікер має окремий шлях. Стікери учасників залишаються в репертуарі своєї групи. PNG-прев’ю та компактні еталони потрібні перевіркам розробки, а сервер використовує готові WEBM і скорочений manifest.

## Пам’ять і підключення

Кожна група має окремі історію, нотатки, стилі, ігри та черги. Теми тієї самої групи пов’язані контекстом. Дані іншої групи та профіль/історія власника ChatGPT в цей контекст не потрапляють. Люмен читає нові доступні події Telegram й не отримує історію до додавання. Для відповідей і допоміжних підсумків обмежений контекст цієї групи передається OpenAI; давні матеріали може знаходити пошуком.

«Люмен, призупини пам’ять» зупиняє новий запис. Поновити або очистити всю пам’ять може власник підключення чи адміністратор. «Люмен, забудь [фрагмент]» видаляє фрагмент і пов’язані похідні дані цієї групи. Звичайне видалення повідомлення в Telegram не сповіщає бота. Копії у провайдерів і резервних копіях мають окремий життєвий цикл.

ChatGPT у чинній інсталяції вже підключений; повторний вхід і постійно ввімкнений Termux не потрібні. Власник відкриває особисте посилання активації у Telegram, натискає Start і додає Люмена його кнопкою. Для фонової розмови потрібні вимкнений Privacy Mode або відповідні права бота. Стороння непідключена група не отримує доступ до підписки.

Прохання в чаті не створює нового зовнішнього доступу або платної функції. Невеликі обчислення працюють в ізольованому JavaScript без доступу до сервера, файлів і мережі; довільні Node/Python або встановлення програм із чату не підключені.

## Розробка й запуск

Потрібні Node.js 24 і PostgreSQL. Тести використовують ізольовану PGlite та контрольовані зовнішні взаємодії; PDF-перевірки потребують `pdftotext` із `poppler-utils`.

```sh
npm ci --include=dev
npm test
npm run package:release
npm run verify:release
```

`npm run build` компілює тільки `src` у `dist/src`. `npm run build:test` компілює тести в `.test-build`. `npm run build:release` збирає окремий `.release` з production-залежностями та потрібними ресурсами. `.release` — відтворюваний вихід збірки, його не комітять.

Для налаштованої інсталяції з відповідним `RUNTIME_DIR`:

```sh
cd .release
npm start
```

Для нового локального підключення є майстер `npm run setup` та [інструкція ChatGPT](docs/CONNECT_CHATGPT.md). Наявну сесію повторно не підключати. Ручні тестові інструменти й їхні передумови описані в [tools/diagnostics](tools/diagnostics/README.md).

## Випуск і джерела

Чинний хостинг — Render worker із приватною PostgreSQL і постійним диском. Нові ресурси для цього пакета не потрібні. Цільова схема: звичайний `git push`, успішний CI для цього SHA, Render `After CI Checks Pass`, побудова та запуск `.release`. Перед публікацією перевірити фактичні налаштування за [RELEASING](docs/RELEASING.md).

У Git залишаються код, потрібні тести/еталони, готові ресурси й інструкції. Пробні відео, джерела анімації та журнали виконання зберігаються окремо: [авторський архів](https://chatgpt.com/library?file_id=libfile_eacd327e079c8191ac88bc43375e458a&account_id=personal), [матеріали до очищення 1.13.2](https://chatgpt.com/library?file_id=libfile_5cb705ea45848191b89cdef4e5bce93e&account_id=personal). Пам’ять чату містить рішення й посилання, але не замінює файли.

Історичні `RELEASE_*` описують свій випуск. Актуальні правила запуску й перевірок містяться в [OPERATIONS](docs/OPERATIONS.md) та [RELEASING](docs/RELEASING.md).
