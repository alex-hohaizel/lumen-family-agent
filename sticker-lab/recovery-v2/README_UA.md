# Люмен: виправлення після відхилення векторної пари

Стан: одна нова проба, потребує оцінки користувача. Сервер і живий стікерпак не змінюються.

Попередні два векторні стікери відхилені через втрату впізнаваності, механічні рухи та роз’єднані частини. Їх не використовувати як затверджений шаблон для 50.

Нова проба використовує оригінальний `assets/lumen.png` як еталон для вбудованого генератора зображень. Згенеровані цілісні ключові пози з пухнастою фактурою та костюмом Люмена. Позу, де лапка міняє бік, виключено із послідовності.

Проміжні кадри обчислюються локально відкритим RIFE v4.6 на процесорі. Анімуються цілі зображення персонажа, без розрізання тіла на окремі лапки/рот/очі. Прозорість для WEBM відновлюється через рендери на чорному та білому тлі. Фінальний формат — WEBM VP9, 30 кадрів/с, 2,8 секунди. GIF та MP4 служать для оцінки зовнішності й руху.

Цей метод не є повноцінною тривимірною моделлю й не замінює ручну роботу аніматора. При оцінці потрібно перевіряти впізнаваність обличчя, сталість зубів і очей, цілісність силуету, мотивованість жесту й відсутність розпливання між позами. Перевірка формату та плавності сама по собі не означає схвалення художньої якості.

Для порівняння `Lumen_Original_vs_Recovery_v2.mp4` показує оригінал поруч із новою пробою. Усі 50 стікерів лишаються призупиненими до схвалення нових проб.

Використані інструменти: вбудований image_gen для ключових поз; відкриті локальні RIFE/ncnn, Pillow, NumPy, SciPy та FFmpeg для складання відео. Платні зовнішні генератори відео не застосовувалися.

RIFE: https://github.com/nihui/rife-ncnn-vulkan — реліз 20221029, модель rife-v4.6, CPU `-g -1`. Вихідна картинка: `keyframes-source.png`. Послідовність поз: `sequence.json`. Технічний стан і відсутність художнього затвердження: `REVIEW_STATUS.json`.
