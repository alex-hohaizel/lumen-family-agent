01 / TELEGRAM

Власний бот

Відкрийте офіційний BotFather, надішліть /newbot. Ім’я — Люмен. Telegram запропонує вибрати вільний username із закінченням bot.

У BotFather: /setprivacy → оберіть бота → Disable. Якщо бот уже був у групі — додайте його заново. Права адміністратора не потрібні.

02 / МОДЕЛЬ

Розумний співрозмовник

Підключіть підписку ChatGPT. Це дає доступ до дозволених моделей і її лімітів. Розмови та пам’ять вашого ChatGPT залишаються окремими.

Додаткові можливості та окремий API

Вмикайте лише потрібні модулі. Зображення й розпізнавання голосу з API оплачуються окремо від підписки. За замовчуванням вимкнені.

03 / ВАША ГРУПА

Тільки для вас двох

Налаштування завершаться після успішної відповіді моделі. Потім додайте бота до приватної групи й прив’яжіть її одноразовою командою.

Натисніть посилання, оберіть вашу групу, а потім надішліть у ній:

Додати Люмена до групи

Кожен учасник пише /consent. Після цього Люмен починає зберігати вашу розмову.

Якщо налаштовуєте сервер віддалено, підключення групи спрацює після перенесення захищених налаштувань і запуску на сервері. Для Docker використайте start.sh або інструкцію в README.

Люмен не знає вашої біографії, інших чатів чи запитів. /pause призупиняє збереження. /forget_all очищає активну пам’ять. Зміст старих резервних копій має окремий строк зберігання.
