# Перевірка Люмена 1.1.0

26 жовтня 2026, Europe/Kyiv. Node.js 24.22.1.

Повторно перевірено вхідний архів: **75/75** тестів. Після змін: **93/93**, 10 наборів, без пропусків чи скасувань. Повний протокол — `docs/test-results.txt`.

Перевірки використовують PostgreSQL-логіку PGlite, справжній локальний HTTP-майстер, фіктивні Telegram/модель для зовнішніх викликів, локальну перевірку OIDC-підписів. Успіх цих тестів не означає живого підключення Telegram чи ChatGPT.

Перевірені зміни:

- Окремі стилі двох учасників, збереження після рестарту, природне явне прохання, заборона постійної зміни з разового запиту.
- Адаптивна частота самостійних реплік, участь обох, пауза після мовчання, приглушення ініціативи для складної теми.
- Очищення налаштувань під час забування, повторювана міграція схеми.
- Справжня видача MP4 майстром, правильний MIME, доставка дозволених реакцій.
- Анімований профіль: multipart, правильний бот, хеш версії, відсутність хибного успіху після відмови Telegram.
- Усі попередні перевірки ізоляції, згод, черг, повторів, паузи, пам’яті, ігор та OAuth.

Відео перевірено FFprobe/FFmpeg: H.264, yuv420p, 60 кадрів/с, квадрат, без аудіо, кожен файл менший за 2 MiB. Результат і перевірка початку/кінця циклу — `docs/video-qa.json`. Інтерполяція працює з оригінальними 6–7 позами, без нових згенерованих жестів.

`render.yaml` пройшов поточну офіційну JSON Schema, завантажену з Render у цьому сеансі. Render CLI та живий Blueprint deploy не виконані. Docker daemon відсутній, Docker-образ тут не збирався.

Live smoke-перевірка чесно показала відсутні Telegram-токен, URL бази й вибрану модель. Сесія ChatGPT також відсутня. Реальний груповий діалог не перевірений. Подальші кроки та блокування — `docs/RELEASE_1_1.md`.
